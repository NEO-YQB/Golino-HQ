# 👑 Golino HQ (Executive Operations Hub)

سامانه مستقل، امن و لوکس مدیریت عامل پلتفرم **گلینو (Golino)** برای نظارت، برنامه‌ریزی و تعامل زنده با ایجنت‌های هوش مصنوعی دپارتمان‌های مختلف.

---

## 🌟 ویژگی‌های کلیدی
- **داشبورد وضعیت سازمان (Executive Overview):** پایش لحظه‌ای سلامت تیم‌ها، تسک‌های جاری و صف کارهای در انتظار تایید.
- **اتاق جلسات ۱ به ۱ با مدیر هر دپارتمان (1-on-1 Meeting Room):** چت تعاملی و هوشمند با مدیران دپارتمان‌ها (سئو، سوشال، پشتیبانی و...)، ارائه فیدبک و اعمال خودکار اصلاحات توسط مدیر روی کارشناسانش.
- **اتاق جلسات گروهی هیئت‌مدیره (Boardroom):** فراخوانی همزمان چند مدیر، طرح ایده‌ها و کمپین‌ها، و تقسیم خودکار وظایف بین دپارتمان‌ها.
- **کارتابل تسک‌ها و کنترل کیفی:** تایید نهایی خروجی‌های آماده انتشار، نظارت بر موعدهای تحویل و گیت‌های ممیزی.
- **گزارش‌های دوره‌ای راست‌چین (RTL Reports):** بررسی شاخص‌های عملکرد (KPIs)، دستاوردها و موانع با فونت وزیرمتن.
- **صندوق پیام‌های مستقیم (Direct Escalations):** دریافت فوری هشدارها و خطاهای بحرانی از سوی اعضای تیم‌ها.

---

## 🛠 استک فنی
- **فریم‌ورک:** Next.js 14 (App Router) + TypeScript
- **استایل و تم:** Tailwind CSS (طراحی مدرن لوکس دارک، سازگار با موبایل PWA و RTL)
- **موتور هوش مصنوعی:** ادغام مستقیم با Google Gemini API
- **استقرار سرور:** کانتینریزه با Docker، کاملاً سازگار با **Coolify** روی دامنه‌ی اختصاصی `https://hq.golino.shop`

---

## 🚀 نحوه اجرا در محیط لوکال

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` بسازید:
```bash
cp .env.example .env
```
در صورت تمایل، کلید `GEMINI_API_KEY` را در فایل `.env` قرار دهید تا مدیران دپارتمان‌ها با هوش مصنوعی پاسخ دهند (در غیر این صورت سیستم با پاسخ‌های هوشمند پیش‌فرض کار می‌کند).

### ۳. اجرای سرور توسعه
```bash
npm run dev
```
سامانه روی آدرس `http://localhost:3005` در دسترس خواهد بود.

---

## 🚢 دپلوی روی Coolify (سرور اصلی گلینو)

۱. در پنل Coolify روی **+ New Resource** کلیک کنید.
۲. گزینه **Public/Private Git Repository** را انتخاب کنید و آدرس ریپوی خود را وارد نمایید:
   ```
   https://github.com/NEO-YQB/Golino-HQ.git
   ```
۳. در بخش **Build Pack**، حالت **Dockerfile** را انتخاب کنید.
۴. در بخش **Domains** آدرس زیر را تنظیم کنید:
   ```
   https://hq.golino.shop
   ```
۵. پورت کانتینر را روی `3005` قرار دهید.
۶. متغیر `GEMINI_API_KEY` را در بخش Environment Variables در صورت تمایل تعریف کنید.
۷. روی **Deploy** بزنید.

پروژه به صورت خودکار بیلد، تست و با گواهی SSL رایگان روی `https://hq.golino.shop` بالا می‌آید!
